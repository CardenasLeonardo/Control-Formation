\section{Integración: Consenso + PVA}
\setlength{\columnseprule}{0pt}
\onecolumn
\centering
\resizebox{0.98\linewidth}{!}{%
\begin{tikzpicture}[
    node distance=1.4cm,
    box/.style={draw=colorH, thick, rounded corners, minimum height=2.6cm, align=center, fill=colorH!8, font=\normalsize},
    lbl/.style={align=center, font=\normalsize}
]

\node[lbl] (vec) {Vecinos\\ $j \in \mathcal{N}_i$\\ $\mathcal{G}(t)$};

\node[box, minimum width=6.0cm, right=of vec] (cons) {
    \textbf{Consenso}\\[4pt]
    $\dot{\mathbf{x}}_i = -\displaystyle\sum_{j\in\mathcal{N}_i} a_{ij}(\mathbf{x}_i-\mathbf{x}_j) - \beta\, b_i^0(\mathbf{x}_i-\mathbf{x}_0-\mathbf{r}_i)$\\[6pt]
    $u_{ref} = \begin{bmatrix} k_1\, a_i \cos\alpha_i \\ k_2\,\alpha_i + k_1 \sin\alpha_i \cos\alpha_i \end{bmatrix}$
};

\node[box, minimum width=5.4cm, right=of cons] (pva) {
    \textbf{PVA}\\[4pt]
    $u^{*} = \displaystyle\arg\min_{u} \tfrac{1}{2}\|u-u_{ref}\|^2$\\[6pt]
    sujeto a $A_i v + B_i \omega \le C_i$
};

\node[lbl, right=of pva] (rob) {Robot $i$\\ no holonómico\\ $u^{*}=(v,\omega)$};

\draw[->, thick, colorH] (vec) -- (cons);
\draw[->, thick, colorH] (cons) -- node[above, font=\normalsize]{$u_{ref}$} (pva);
\draw[->, thick, colorH] (pva) -- node[above, font=\normalsize]{$u^{*}$} (rob);

\end{tikzpicture}}

\medskip
El consenso genera $u_{ref}$ respetando la geometría de formación. El PVA proyecta $u_{ref}$ sobre el conjunto admisible y produce $u^{*}$, la velocidad que finalmente actúa sobre el robot no holonómico.
