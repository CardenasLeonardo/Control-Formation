\begin{abstract}
Este documento describe los patrones de composición de launch files en ROS~2 orientados a simulación multi-robot con Gazebo. Se explica cómo un único launch file orquesta el arranque de un simulador, la descripción de robots, el spawn de modelos, y los nodos de control, coordinando el orden de lanzamiento mediante acciones temporizadas.

Se analiza en detalle la estructura de IncludeLaunchDescription, TimerAction, OpaqueFunction, y el patrón de namespaces para múltiples robots, usando como caso de estudio el launch file de experimentos de consenso de promedio del proyecto de control de formación multi-robot desarrollado en mi investigación para Tesis.
\end{abstract}
